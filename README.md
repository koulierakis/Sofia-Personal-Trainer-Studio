# Sofia Personal Trainer Studio

Αυτόνομη εφαρμογή Functional Training & Pilates. **Δεν συνδέεται με το παλιό repository `koulierakis/Sofia` ή με το Giannis AI Studio.**

## Τρέχουσα φάση
- Αρχική οθόνη επιλογής Functional / Pilates.
- Functional: αναζήτηση ασκήσεων, φίλτρα μυϊκών ομάδων, εξοπλισμού, επιπέδου, προγράμματα, διατάσεις.
- Εισαγωγή/εξαγωγή δεδομένων JSON (schema `{exercises, programs}`) με ασφαλή συγχώνευση βάσει ID.
- Φωνητική αναζήτηση ελληνικών μέσω διαθέσιμης τεχνολογίας browser, με σαφή σφάλματα υποστήριξης.
- Προβολή 4 φάσεων μόνο εφόσον υπάρχουν εικόνες, με ρητή επισήμανση των παλιών SVG placeholders.

## Εκτέλεση
`npm start` (Node.js 20+), ανοίξτε `http://localhost:3100`. Προαιρετικά `PORT=3100`.

## Εισαγωγή αρχικών δεδομένων
Χρησιμοποιήστε το συγκεντρωτικό `Sofia_Functional_100_Exercises_10_Programs_Import.json` από την προηγούμενη συνομιλία. Πρώτα κάντε εξαγωγή ασφαλείας. Τα παλιά προγράμματα/ασκήσεις δεν διαγράφονται. Οι φωτογραφίες SVG των παλιών πακέτων είναι *placeholders*, όχι πραγματικές τεχνικές απεικονίσεις.

## Σημαντικό
Αυτή είναι η αρχική επαναδημιουργία της αυτοτελούς βάσης στο νέο GitHub repository, όχι συγχρονισμός των τελευταίων μη αναρτημένων αλλαγών του τοπικού φακέλου. Οι πρωτότυπες σύνθετες ασκήσεις θα προστίθενται μόνο με σαφείς οδηγίες και κατάσταση `requiresCoachReview` έως την αξιολόγηση από προπονητή.
