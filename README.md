# Μπέμπα μου Personal AI Studio

Εφαρμογή Personal Training Studio για Functional Training & Pilates, αναπτυγμένη σε **React + TypeScript + Vite + Tailwind CSS**.

## Χαρακτηριστικά
- **Αρχική οθόνη επιλογής Functional / Pilates** με άμεση πρόσβαση στις αντίστοιχες βιβλιοθήκες.
- **Βιβλιοθήκη Ασκήσεων & Διατάσεων**: 100 κανονικές ασκήσεις και 208 προηγμένοι πρωτότυποι συνδυασμοί.
- **Φίλτρα & Αναζήτηση**: Δυναμικό φιλτράρισμα βάσει μυϊκής ομάδας, εξοπλισμού και επιπέδου (Beginner, Intermediate, Advanced) με άμεση αναζήτηση κειμένου.
- **Εικονίδιο & εγκατάσταση σε κινητό και υπολογιστή**: Κεφαλαίο S σε premium χρυσό/μαύρο, favicon, manifest και όνομα εγκατεστημένης εφαρμογής «Μπέμπα μου»· κατά το άνοιγμα εμφανίζεται «Μπέμπα μου AI Studio». Το layout προσαρμόζεται σε μικρές και μεγάλες οθόνες.\n- **Φωνητική Αναζήτηση (Web Speech API)**: Αναγνώριση φωνής στα ελληνικά (`el-GR`) με αυτόματη εξαγωγή επιπέδου, μυϊκής ομάδας και ορίου αποτελεσμάτων.
- **Μπέμπα μου AI Coach & Precision Motion Engine**: Ελληνικό chat/φωνητική είσοδος, προαιρετικό τοπικό Ollama χωρίς API key, ντετερμινιστική ανάλυση υποστηριζόμενων μοτίβων, IMAGE/VIDEO prompts, structured pose export και σαφής ένδειξη αβεβαιότητας. Τα prompts δεν δηλώνουν ότι δημιουργήθηκαν ή επικυρώθηκαν εικόνες. Λεπτομέρειες: `docs/SOFIA_AI_COACH.md`.
- **Αναπαραγωγή Περιγραφών Καρέ (Frame Player)**: Βηματικός και αυτόματος player με ρύθμιση ταχύτητας (0,5× έως 3×) και κλειδωμένη αναφορά προτύπου/στούντιο (SHA-256 reference lock).
- **Σύστημα Αξιολόγησης Προπονητή (Coach Review)**: Έγκριση ή απόρριψη προτάσεων ασκήσεων με ασφαλή διατήρηση στο τοπικό περιβάλλον και δυνατότητα εξαγωγής/εισαγωγής.
- **Δομημένα Προγράμματα 60 λεπτών**: 10 πλήρη προγράμματα με αναλυτικά blocks και άμεσους συνδέσμους προς τις ασκήσεις.
- **Εισαγωγή / Εξαγωγή JSON**: Δημιουργία αντιγράφων ασφαλείας (`Sofia_Backup_YYYY-MM-DD.json`) και συγχώνευση βάσει ID χωρίς απώλεια δεδομένων.

## Ανάπτυξη & Εκτέλεση
- `npm run dev`: Εκκίνηση του Vite development server στη θύρα 3000 (`0.0.0.0:3000`).
- `npm run build`: Παραγωγή βελτιστοποιημένου bundle για παραγωγή.
- `npm run lint`: Έλεγχος τύπων TypeScript (`tsc --noEmit`).
- `npm test`: Εκτέλεση της σουίτας αυτοματοποιημένων δοκιμών με `tsx --test`.
